# BLACKCAT VIDEO STUDIO · OpenMontage

Herramienta de referencia: https://github.com/calesthio/OpenMontage (AGPL-3.0).

## Instalación oficial en equipo de edición
- Python 3.10+, Node.js 18+ y FFmpeg.
- `git clone https://github.com/calesthio/OpenMontage.git`
- `cd OpenMontage` y `make setup` (o instrucciones Windows PowerShell del README oficial).
- Abrir la carpeta en Codex y usar el prompt siguiente. OpenMontage no se instala mediante el conector de GitHub por sí solo.

## Prompt maestro
Crear para BLACKCAT STREETWEAR (El Salvador, https://blackcatsv.shop, https://youtube.com/@blackcatsv16) un Short vertical original de 9:16, 18-30 segundos, profesional, enfocado en fabricación de camisas DTF y oversize. Estilo editorial de estudio gris frío, negro y blanco; contraste premium; tipografía geométrica Inter/Sora, sin logotipo de gato, sin neones ni fondos cálidos. Mostrar procesos auténticos solo si se dispone de metraje propiedad de BLACKCAT: preparación del diseño, impresión DTF, prensado, acabado, prenda real, CTA a web. No fabricar supuestas imágenes reales de nuestro taller. Usar medios propios o licencias verificadas. Música original o con licencia comercial; subtítulos precisos. No incluir precios no verificados. Generar storyboard y muestra de tres escenas antes del render completo. Exportar MP4 H.264, 1080x1920, 25-30fps, audio AAC; solicitar aprobación antes de publicar.

## Ideas de cuatro primeros Shorts
1. De diseño a prenda: flujo DTF real, con microdetalles (requiere clips del taller)
2. Oversize vs Regular: corte y caída con prendas reales (requiere clips de prendas)
3. Tres ideas para combinar una oversize: contenido editorial sin afirmaciones comerciales no verificadas
4. Cómo comprar en blackcatsv.shop: recorrido visual del proceso (capturas aprobadas)

El teaser 15s actual es una animación original de demostración y NO sustituye el video de taller. Los flujos automáticos deben guardar archivos en revisión, no publicar sin aprobación.
